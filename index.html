О колледже

Бишкекский автомобильно-дорожный колледж им. К. Кольбаева — учебное заведение среднего профессионального образования. Колледж ведет историю с 1957 года и готовит специалистов для дорожной, транспортной и IT-сферы.

В структуре IT-направления специальность 230111 «Программирование в компьютерных системах» ориентирована на подготовку техников-программистов.

Система предназначена для учета выпускников ПКС: хранения данных, поиска, анализа трудоустройства и подготовки отчетности по выпускникам.

ПКС — одна из востребованных IT-специальностей в системе среднего профессионального образования. Обучение направлено на подготовку специалистов, которые умеют разрабатывать, тестировать, внедрять и сопровождать программное обеспечение, работать с базами данных и веб-технологиями.

О проекте

Тема: Разработка автоматизированной информационной системы для учета трудоустройства выпускников ПЦК «Программирование в компьютерных системах».

Цель проекта: автоматизация учета выпускников, хранение сведений об их трудоустройстве и формирование отчетной информации для ПЦК.

Учебное заведение: БАДК — Бишкекский автомобильно-дорожный колледж им. К. Кольбаева.

Специальность: 230111 Программирование в компьютерных системах.

ПЦК: Программирование в компьютерных системах.

Председатель ПЦК: Шабиева Айзада Эмилбековна.

Основные функции: добавление, редактирование, удаление, поиск, фильтрация, учет статуса трудоустройства, статистика по годам и экспорт данных в CSV.

Использованные технологии: HTML, CSS, JavaScript, LocalStorage.

Разработчик: Туратбеков Сапарбек Нурланович, группа ПКСК-9-1-23.
